# 🏦 Loan Approval Prediction (End-to-End ML Project)

## 📌 Overview

This project presents an end-to-end machine learning solution to predict whether a loan application will be approved based on applicant information, financial details, and loan-related attributes.

The project covers data understanding, data preprocessing, exploratory data analysis, model development, and performance evaluation. It demonstrates how machine learning can support more efficient and data-driven loan approval decisions.

The project report is provided as an HTML file.

---

## 🎯 Objective

- Predict loan approval outcomes (`Approved` / `Rejected`).
- Identify the key factors influencing loan approval decisions.
- Support data-driven decision-making in the lending process.
- Demonstrate a complete machine learning workflow.
